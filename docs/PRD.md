# Task Goblin — Product Requirements Document (PRD)

**Version:** 0.4  
**Status:** Active Development (Milestones 1-4 Complete)  
**Platform:** Windows Desktop/Web MVP → Android later  
**User:** Single user (personal productivity)

---

# 1. Product Vision

## Overview

Task Goblin is a personal productivity application focused on helping the user capture ideas, intentionally plan their day, and focus on meaningful work.

The app is designed around one question:

> "What should I be doing right now?"

Task Goblin is not intended to replace every productivity tool. It is a simple personal system for:

1. Capturing thoughts quickly.
2. Organizing tasks intentionally.
3. Choosing what matters today.
4. Executing focused work.
5. Reviewing progress.

---

# 2. Product Principles

## Capture First

New ideas should require almost no effort to record.

When a thought appears, the user should not need to decide:

- Priority
- Project
- Due date
- Category
- Organization

Everything starts in the Inbox.

---

## Plan Intentionally

Organization happens during Daily Planning.

The user decides:

- What matters today.
- What can wait.
- What needs attention.
- What should be ignored.

---

## Today Comes First

The app should avoid overwhelming the user.

The default experience should focus on:

- Today's priorities
- Current habits
- Relevant schedule information
- Important decisions

The complete task backlog should not dominate the experience.

---

## Complexity Must Be Earned

Features should only be added when there is a demonstrated need.

Task Goblin should avoid becoming a complicated project management platform.
